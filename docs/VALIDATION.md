- ESP-IDF 6.1.0 / Xtensa GCC 15.2.0 构建，目标 ESP32-S3；最后一轮编译没有项目编译警告或错误。

- AddressSanitizer / UndefinedBehaviorSanitizer；所有位图字库与 QWeather 图标的索引、RLE 长度和源文件 SHA-256。
