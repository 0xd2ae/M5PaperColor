# PaperColor 实机验收

以下项目需要刷机和真实设备；未完成的项目不得用主机构建结果替代。

1. 先开启 `CONFIG_PC_PANEL_TEST`，确认黑、白、红、黄、蓝、绿顺序正确，400×600 方向和中文笔画清晰。拍摄实屏照片与预览对比。
2. 关闭测试模式。无需密码连接开放热点 `PaperColor-Setup`，确认 `192.168.4.1` 可访问、家庭 Wi-Fi 连接后网页仍可用，并验证十分钟退出；Wi-Fi 失败、错误天气凭据不得覆盖旧配置。
3. 使用有 v1 天气及 GeoAPI 权限的和风天气账户，选择城市，检查实际当前温度、三天预报及正确日期；切换城市后不显示旧缓存。
4. 顶部 C 短按返回今天并刷新，长按三秒只进入配置；侧上 A 上月、侧下 B 下月。深度睡眠后逐个测试唤醒，测试快速反向翻月与屏幕 BUSY 期间按键。
5. 检查五分钟浏览超时回本月，不额外发起天气请求；午夜、月底、跨年更新正确。断网后 RTC 继续走时，天气标离线／过期。
6. 检查年度表导入及断电恢复；确认 2026-02-14、02-28 和 10-10 标“班”，春节区间标“休”，2027 未导入时提示缺失。
7. 断电后重新上电，确认配置及缓存恢复；确认无有效 RTC 时间时显示待校时。不要将人为设定时间的测试结果作为联网校时证据。
8. 测量一次联网与整屏刷新能量、休眠电流，检查音频、SD、RGB、Grove 和屏幕电源状态。按真实更新频率和电池可用容量估算续航。
9. 检查每次刷新结束 BUSY 为高，睡眠期间无持续唤醒循环；异常 BUSY 超时应有日志并在下一轮重新初始化。
10. 串口日志应出现 `indoor xx.x C yy%`；与独立温湿度计并排比较，记录机壳内偏差。屏幕“室内”行与日志取整一致，拔除或短路模拟失败时显示“室内 --”。
11. RGB：上电绿、联网蓝、刷新黄、配置紫闪、休眠前白色渐暗；确认颜色顺序（GRB）正确、两颗灯都亮，整点唤醒不亮状态色。用可调电源压低电池电压验证 ≤20% 与 ≤5% 红色警告，深度睡眠电流不因 RGB 增加。

记录设备硬件版本、固件 SHA-256、测试日期、天气账户接口权限、测试结果与照片。电池百分比为粗略电压估计，不能用于校准续航。
